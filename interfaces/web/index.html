REAL MOUSE / KEYBOARD CONTROL—
Full remote control of this PC's actual input devices — a materially bigger security surface than anything else ORION does. There are no manual buttons here on purpose: control happens through conversation with ORION ("click the Save button", "type this into the search box") rather than a point-and-click proxy panel, since that would just be a different way to trigger the same real actions without adding any real safety. Every action (move/click/type/press) is DESTRUCTIVE-tier and pauses for your explicit confirmation before it runs — approving a batch runs everything in that batch, so review what's listed before approving. Slamming the mouse into a screen corner aborts mid-action (pyautogui's own failsafe, independent of ORION).
